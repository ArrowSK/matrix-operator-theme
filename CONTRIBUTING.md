# Contributing

Contributions should be small, focused, and compatible with Home Assistant's native frontend theme variables.

## Before opening an issue or pull request

- Test in both dark and light modes.
- Check text and control contrast in the affected interface.
- Keep the theme static; do not add JavaScript, analytics, remote fonts, or background animation.
- Do not include screenshots, logs, entity IDs, device names, addresses, location data, access URLs, or credentials from a personal Home Assistant installation.

## Changes

Describe the Home Assistant frontend area affected, the expected appearance, and how you tested it. Keep palette changes narrowly scoped and document any accessibility trade-off.
